# TransferGuard
Прототип для банковского кейса ITU Hackathon 2026. Симулятор объясняет риск до подтверждения перевода и позволяет проверить, как ответы клиента меняют рекомендацию. Все операции вымышлены.

## Локальный запуск
Требуются Node.js 24 и pnpm 11. В каталоге проекта выполните:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Откройте http://localhost:3000. Для показа нажмите «Продолжить» на экране перевода. Пройдите обычный перевод, крупную покупку с ответами «Нет» и звонок из банка с ответами «Да». В последнем случае предупреждение появляется до подтверждения, а клиент может отменить операцию. Два последних сценария используют одинаковую сумму и получателя.

## Проверки
```sh
pnpm test
pnpm typecheck
pnpm build
pnpm exec playwright install chromium
pnpm test:e2e
```

Сквозные тесты самостоятельно запускают production-сервер после сборки. Для установленного Edge задайте TEST_BROWSER_CHANNEL=msedge.
