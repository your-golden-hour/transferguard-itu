# Архитектура
Форма Next.js отправляет сумму, идентификатор получателя и три ответа в POST /api/risk/evaluate. Сервер читает до 2048 байт, валидирует JSON строгой схемой Zod и вызывает чистую функцию evaluate. Выбор сценария заполняет форму. Идентификатор сценария в API отсутствует.

Обычная сумма в фиксированном учебном профиле — 20 000 ₸. В rules-v0.1 новый получатель добавляет 15 баллов, превышение тройной обычной суммы — 20, давление — 20, представление сотрудником банка — 15, «безопасный счёт» — 35. Итог ограничен 100. Границы среднего и высокого уровня — 30 и 60. Упоминание «безопасного счёта» самостоятельно вызывает рекомендацию остановиться. Незнакомство лично исключено из первой версии, поскольку история переводов сама по себе его не доказывает.

Ответ включает уровень, причины с весами, список неизвестных ответов, действие и версию правил. Баллы служат для сравнения синтетических ситуаций. Калибровка на реальных данных отсутствует.
