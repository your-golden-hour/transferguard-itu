# TransferGuard · первая итерация
Клиент может подтвердить платёж под давлением звонящего. Гипотеза проекта — несколько вопросов до подтверждения помогают заметить такое давление. Польза для реальных клиентов требует отдельной проверки.

## Пользовательский путь
Клиент вводит сумму и выбирает получателя в симуляторе мобильного банка. При переходе к подтверждению приложение запрашивает серверную оценку. При повышенном риске оно показывает три вопроса. При признаках мошенничества оно показывает отдельный экран с причиной и действием «Отменить перевод». На экране подтверждения клиент также может сообщить об инструкциях по телефону.

## Критерии приёмки
- Перевод знакомому по истории на 12 000 ₸ даёт краткий результат без обязательного опроса.
- Перевод новому получателю на 90 000 ₸ сначала вызывает вопросы. При трёх отрицательных ответах интерфейс предлагает сверить реквизиты.
- Для той же операции три положительных ответа вызывают предупреждение и совет связаться с банком самостоятельно.
- Изменения ввода сбрасывают прежний результат. Ответ «неизвестно» сохраняется отдельно.
- Демо работает только с двумя вымышленными получателями и суммой в целых тенге. Данные запросов не сохраняются приложением.
