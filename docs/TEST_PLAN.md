# Проверки
Модульные и интеграционные тесты выполняются встроенным раннером Node. Они проверяют три ситуации, запрос уточнений, границу 60 000 ₸, отдельное правило «безопасного счёта», неполные ответы и ошибки формата, схемы и размера тела.

Playwright проходит форму в браузере при ширине 1280 и 390 пикселей. В двух сценариях он отвечает на три вопроса и повторяет запрос. Проверяются итоговое предупреждение и отсутствие горизонтальной прокрутки.

Перед показом отдельно проверить публичную ссылку с телефона, доступность с клавиатуры и понятность рекомендаций участникам. Прохождение сценариев измеряет работоспособность программы. Для оценки качества обнаружения мошенничества потребуется размеченная выборка.
